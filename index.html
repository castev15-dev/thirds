Export a CSV from your bank's website, choose its account, map the columns, then review every row before importing.

On this device

Column labels and descriptions help suggest categories. Check credits carefully: a refund is different from income. Mark card payments and transfers as Transfer to avoid counting them as purchases. Pending rows are excluded when a status column is mapped.

ImportDateDescriptionAmountTypeCategoryReview

Duplicates use bank IDs when available, otherwise account + date + amount + description + occurrence count. Identical legitimate purchases already logged manually may need manual review. The import leaves income estimates and balance snapshots unchanged.

About automatic bank linking

This standalone version uses manual balances and local CSV imports. Automatic syncing needs a hosted backend and an authorized bank-data provider such as Plaid. The server must keep provider credentials and access tokens private. It may involve provider fees and sharing data with that provider.

A watchlist you can explain

Starter examples for your research. Edit or replace them, enter current holding values, and set target percentages of your brokerage stock / fund holdings. Leave room for holdings outside the list if needed.

Targets across this list must add up to 100% or less. Unused target percentages leave room for holdings outside this list. Holding values and optional quotes are entered by you; the app does not refresh them. These targets do not measure diversification across your Roth or other accounts.
